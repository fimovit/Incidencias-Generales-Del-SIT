Sincronización con Google Sheets y Google Calendar

Conecta este sistema a una hoja de Google Sheets para llevar control de tus clientes, tu catálogo de productos, tus paquetes de show y tus cotizaciones — y para que cualquier computadora, celular o copia de este archivo (incluyendo la publicada en GitHub Pages) muestre siempre la misma información, en vivo. Los clientes, los productos (catálogo de servicios con precios), los paquetes de show (Básico/VIP/The Show) y las cotizaciones van en ambas direcciones: lo que agregues, edites o elimines aquí se envía a la hoja de inmediato, y lo que haya en la hoja se vuelve a descargar por completo al abrir el sistema y cada 20 segundos mientras está abierto — nunca se queda mostrando una versión vieja guardada en este navegador. Si dos computadoras editan lo mismo casi al mismo tiempo, gana lo que se guardó de último en la hoja. Además, cada cotización con fecha de evento crea o actualiza automáticamente un evento en tu Google Calendar (se borra solo si declinas la cotización o la eliminas).

Sincronización: inactiva — no se ha configurado ninguna URL.

¿Ya tenías clientes y cotizaciones guardados antes de conectar Google Sheets? Usa este botón una sola vez para enviar todo lo que ya existe aquí hacia la hoja (los que se creen de ahora en adelante ya se envían solos, no hace falta repetirlo).

¿Quieres que este navegador quede exactamente igual a lo que hay en la hoja (por ejemplo, si aquí quedó algo de prueba o duplicado)? Este botón reemplaza todos los clientes, productos, paquetes de show y cotizaciones guardados en este navegador por lo que traiga la hoja de Google Sheets en ese momento. No borra nada de la hoja en sí — solo lo que hay aquí. Si no logra conectarse, no borra nada.

¿No tienes el script todavía? Pídele a Claude el archivo Code.gs con el código listo para copiar en tu hoja de Google Sheets (Extensiones → Apps Script), junto con los pasos para publicarlo como aplicación web y obtener esta URL.

Respaldo y compartir datos

Toda la información (clientes, productos, cotizaciones, paquetes y ajustes) vive en este navegador. Si envías el archivo .html tal cual a otra persona, sus datos no viajan con él — cada navegador tiene su propio almacenamiento. Usa las opciones de aquí para llevar tu información a otro lado.

Al vincular, cada cambio que hagas aquí (agregar un cliente, una cotización, etc.) se guarda automáticamente dentro de este mismo archivo .html en tu computadora — sin descargar nada. Así, cuando copies o envíes ese archivo a otra PC, ya tendrá tu información más reciente. Disponible en Chrome o Edge de escritorio; al activarlo, elige el mismo archivo que tienes abierto para que se sobrescriba a sí mismo.

Alternativa manual: genera una copia de este mismo sistema, pero con toda tu información actual ya incluida adentro. Útil si no puedes usar el guardado automático de arriba.

El respaldo en .json es solo para guardar/restaurar tu información (por ejemplo, para pasar tus datos a este mismo archivo en otra computadora). Importar un respaldo reemplaza por completo los datos actuales.
